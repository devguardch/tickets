# devguard Tickets

Report bugs, questions and feature requests for devguard here.

**[→ Open a new ticket](https://github.com/devguardch/tickets/issues/new/choose)**

## Before you write

- **Search [existing issues](https://github.com/devguardch/tickets/issues?q=is%3Aissue) first.** If your problem is already there, add a comment instead of a new ticket — more voices on one ticket beats five duplicates.
- **One ticket per problem.** Two unrelated bugs in one ticket means one of them gets forgotten.

## What makes a ticket we can fix fast

1. **A title that says what is wrong**, not that something is wrong. "Images are missing in the exported policy PDF" — not "PDF broken".
2. **The three lines that matter:** what you did, what you expected, what happened instead.
3. **Where it happened.** The page URL, or the path through the app (Policies → Edit → Export PDF).
4. **A screenshot or screen recording.** Drag it straight into the ticket. For anything visual this is worth more than a paragraph.
5. **Does it happen every time?** Once, sometimes, or always — and if you found a way to make it happen, the steps.

## Please don't post

Passwords, API keys, or personal data of your employees or customers. Blur them in screenshots. If a ticket needs sensitive data to be understood, say so and we will find another channel.

## What happens next

We read every ticket. You will get a reply in the ticket itself, so keep notifications on for it. Labels like `schnell` or `wochen` are our internal estimate of effort — you don't need to set anything.

For anything urgent or confidential, email [support@devguard.ch](mailto:support@devguard.ch) instead.
